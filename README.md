# Юлия Волчаренко — лендинг

## Что внутри
- `index.html` — основной лендинг
- `assets/style.css` — стили, адаптив, анимации
- `assets/script.js` — модальные окна, cookie-баннер, валидация формы
- `send.php` — серверная часть отправки заявки
- `img/portrait-light.webp` и `img/portrait-red.webp` — оптимизированные фото

## Локальный запуск
1. Открой папку `dist`
2. Запусти локальный сервер:
   ```bash
   python -m http.server 8080
   ```
3. Открой `http://localhost:8080`

## Деплой на хостинг
1. Загрузи содержимое папки `dist` на хостинг
2. Убедись, что хостинг поддерживает PHP
3. Проверь, что `send.php` имеет права на запись
4. При необходимости поменяй email получателя в `send.php`

## Что заменить перед запуском
- контакты в `index.html`
- email получателя в `send.php`
- ссылки на соцсети
